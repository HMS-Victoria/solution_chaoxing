# 输入到光标 v1.0.0（Windows x64 打包版）

将自己的文本逐字输入当前前台输入框。**包已生成，实际环境验收待完成**，尤其是未安装 Python 的全新 Windows 用户验收；本版本不作“全部验收通过”的承诺。

## 下载与使用

下载本页 Assets 中的三个文件：

- `输入到光标-Windows-x64.exe`：唯一主程序，双击运行。
- `使用说明.txt`：中文步骤、停止方式与窗口切换注意事项。
- `SHA256SUMS`：程序与说明的 SHA-256 校验值。

流程：双击 exe → 粘贴文本 → 选择目标窗口 → 按 F8；也可点击“开始输入”后在倒计时内切换目标。停止使用工具的“停止”按钮或关闭程序；F8 不负责停止。

发行目标为 Windows 10/11 x64，内置 Python/Tk，不需要另装 Python、联网、账号或模型。正常使用不要求管理员权限；让目标程序也以普通权限运行。源码压缩包及 `启动.cmd` 不是免环境发行入口。

## 验证与已知限制

源码回归、包结构、内置运行库、无 Python PATH 的隔离自检均通过；最终包同机两次独立构建哈希一致。候选包在两个独立进程文本框中收到中文/换行/emoji；最终包重新验收了启动及停止倒计时。详见仓库 `docs/release-readiness/2026-09-20/VERIFICATION.md`。

**待验收**：无 Python 新用户/干净 Windows、最终包完整记事本输入回归、输入中停止/中途切窗、Windows 10。自动化短按 F8 本次未观察到触发，需手动核实；可先使用按钮开始。

文字只送往当时的前台窗口，不锁定原窗口。输入中切换焦点可能把后续文字送错位置；先停止再切换。回车可能触发目标程序的发送或执行动作，仅用自己有权输入的安全文本场景。部分编辑器可能拒绝模拟输入，输入后需要核对。

程序未签名，可能出现来源提示；请勿关闭系统安全防护。没有使用真实作业系统作验收对象。
